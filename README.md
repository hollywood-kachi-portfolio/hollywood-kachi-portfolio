# Hollywood Kachi — Premium Cinematographer Portfolio

## Video hover previews
Each project contains:
- a poster/still image: `media/project-01.jpg`
- a muted looping preview: `media/project-01.mp4`

Repeat for projects 02–04.

When a desktop visitor hovers over a project, the still fades and the video preview plays automatically. When the pointer leaves, the preview stops and resets.

### Media folder
Create a folder named `media` beside `index.html` and add:
hero.mp4
hero-poster.jpg
project-01.mp4 / project-01.jpg
project-02.mp4 / project-02.jpg
project-03.mp4 / project-03.jpg
project-04.mp4 / project-04.jpg
portrait.jpg

Keep preview videos short and compressed (roughly 3–8 seconds, H.264 MP4, muted) so the site remains fast.

For the hero, use a short looping cinematic background. For the full project film, you can later add a dedicated project page or video lightbox.
